3　SunoでABC別のBGMを作る
共通の音色・調性と、静かな前向きさを揃えます。歌やナレーションは入れません。以下は公式の推奨値ではなく、この用途の試作設定です。


  1. SunoのCreate → Customを開く。モデルはアカウントで利用できる現行モデルを選び、ABCで同じものに固定。
  2. Instrumental：ON。Lyricsは空欄。Vocal Gender・Persona・Audio Uploadは初回は未指定。
  3. 各「Styles」ボタンの英語文をStyles / Style of Music欄へ貼る。
  4. Advanced Options → Excludeに共通の除外文を貼る。
  5. Weirdness / Style Influenceが表示されるモデルでは表の値から試す。表示されない項目は飛ばす。Audio Influenceは音声アップロードなしなら設定不要。
  6. Titleを設定して生成。40〜60秒に固定生成される保証はないので、長めの曲から安定した区間を選ぶ。無音・急な盛り上がり・歌声混入がないか試聴する。




同じモチーフ・調性は生成への希望であり、一致の保証ではありません。まず各2候補を聞き、語りを邪魔しない3曲を選びます。BGMファイルがまだないため、自動ミックスは今回未実装です。動画編集で合わせる際は声より十分小さくし、冒頭・締めにも急な切れ目を作らないようにします。


公式：Creative Sliders ／ 公式：Exclude ／ 公式：Custom / Instrumental
